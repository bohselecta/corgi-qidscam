# Historical technical report — v0.1

The original Hayden Lindley manuscript and bibliography are preserved here
without changing their research question or historical findings. The readable
historical report is in `docs/history/WHITEPAPER.md`. This is historical source
material, not peer-reviewed acceptance or evidence of v2 production performance.
The v2 protocol and all favorable, neutral and unfavorable findings remain in
`docs/RESEARCH-PROTOCOL-v2.md` and `results/suite-v2.json`.

The manuscript's proposed cross-session and RAG applications are research ideas.
Version 0.2.0 has cold, isolated solves; no real-corpus/model run or cross-session
cache reuse is demonstrated. The receipt explorer inspects actual v2 output.

Optional historical build: `pdflatex main.tex`, `bibtex main`, then
`pdflatex main.tex` twice in this directory with a local TeX installation.
Compilation was not run during this repair; Python and browser use do not need TeX.
No PDF or scientific peer-review claim is shipped.
